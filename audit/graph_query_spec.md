# Graph query specification

## Nodes and edges

The analysis graph is the typed export from `euro_sdt_v2.db`:

- one node per `entity`;
- one edge per accepted claim with subject and object entities;
- edge attributes include `predicate`, `role`, `edge_class`, `grade`, `n_sources`, `quote`, `doc_id`, `doc_path`, `doc_sha256`.

## Edge classes

| Class | Predicates |
|---|---|
| network | `board_member`, `member`, `chair`, `affiliated_with`, `advisory_board`, `founder`, `fellow`, `attendee` |
| occupational | employer and held-position predicates |
| education | `educated_at`, degree and field predicates |
| institutional | commission-service predicates |
| other | residual |

## Filters used in the paper

- Primary graph: accepted assertions only.
- Grade-A view: `grade = 'A'`.
- Network-only view: `edge_class = 'network'`.

`graph/report.md` records the resulting node, edge, component and degree-1 counts. Counts are export counts, not counts of claims, sources or people in `euro_sdt_v2.db`.

## Reproducing

The export is generated by `scripts/plot_graph.py`; the database and export are part of the release manifest.
